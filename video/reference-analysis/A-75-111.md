## Techniques

- **Story structure:** each vignette is a 3–5 s mini-loop. (1) The agent speaks first and proactively ("The latest … numbers came in on Teams. I've been updating your board meeting deck"). (2) A human reaction close-up (smile). (3) A shot of the agent's work happening on a big screen. (4) The human gives a short voice instruction or approval. (5) A reaction/payoff. Two vignettes run in 18 s: Felipe/deck and Jojo/migration.
- **Proactivity as the hook:** every agent line opens with something it already did ("I've been updating…", "I caught… I've already mapped out the changes"). The human only steers ("Get it started, but make sure to first check every flow against the current product before…"). This framing maps directly onto Jiro.
- **Pacing:** cuts every 1.5–3 s. Screen-text shots hold about 1.5–2.5 s, which is long enough to read about 20 words. Close-ups run 1–3 s. Nothing lingers longer than about 3.5 s.
- **Transitions:** only hard cuts. Inside shots there are slow push-ins and drifts, with no whip pans or motion-graphic transitions. The camera is handheld-smooth with shallow depth of field.
- **Making the agent visible:** the agent is a named mascot (a blob with a beret or sunglasses, plus a name pill such as "Felipe" or "Jojo") that physically moves across the UI with its own arrow cursor. Watching it move is how you see it working. A label pill, "Felipe's Computer", tells you whose machine this is, which reinforces the idea that the agent has its own computer.
- **Live-updating UI:** stat tiles tick (40% → 51% → 61%), chart labels build in, and checkboxes tick one by one. Small, legible state changes stand in for "work done".
- **UI framing:** there is no device chrome. The product is shown diegetically on large portrait wall screens inside a warm wood-panelled booth, shot through over-the-shoulder foregrounds. The UI is simplified and huge: chat bubbles take up about 40% of frame width, with about 3 lines of large rounded sans per bubble. Agent bubbles are grey, user bubbles are saturated magenta, and stat cards are on cyan/blue.
- **Typography:** big, light-to-regular rounded grotesk, with bold used only on the second word of slide titles ("Consumer **experience**", "A more ambitious **product roadmap**").
- **Color:** a warm wood/amber environment against cool, saturated mascot colors (blue, magenta, yellow, purple). Each agent has its own color identity, so the frame stays legible at a glance.
- **Captions/narration:** there are no burned-in captions. All words are in-world UI text. Dialogue is implied by voice, and the user's speech turns into a chat bubble.
- **Premium feel:** cinematic shallow depth of field, real actors' faces as emotional punctuation, consistent set design, and restraint (one idea per shot, no on-screen marketing copy within the film).
- **Recording artefact (not a technique):** the host page and Safari chrome are static. The player overlay (pause glyph, scrubber) flickers in and out because the cursor hovers over it. Ignore it.
