## Techniques

- **Story structure in this range: "meet and name your agent" → "it is already working for you."** 18.5–33s is pure character/personalisation (dots morph colour, accessories, get named "Alfred"), then at 35s the payoff is a single chat bubble proving the agent did real work unprompted ("getting your website ready…"), answered with a two-word human reply ("Okay, perfect."). Emotion first, capability second, and capability is shown as an outcome, not a feature list.
- **Pacing:** shots last ~1–3 s. Display/character shots hold longer (2–3 s, e.g. heart dot 27.5–30s) than reaction close-ups (1–1.5 s). Rhythm is consistent alternation: **product on screen → human face reacting → product → face**. That shot/reverse-shot makes the agent feel like a character in a conversation.
- **Transitions:** almost entirely hard cuts. The "transitions" happen *inside* the screen: morphs (orange→green→yellow), accessories swapping, UI rail sliding away, character sliding out of frame, chat bubble fading in. Motion lives in the content, cuts stay clean.
- **Camera:** cinematic, shallow depth of field, slow drifts/dollies, out-of-focus foreground objects (blurred shoulders, lamp pole) to create depth and layering. Over-the-shoulder framing keeps the human in the shot when we look at the UI.
- **Product UI framing:** UI is never shown as a flat screenshot; it is diegetic — displayed on large physical framed screens on a wall in a warm wood-panelled room, filmed at an angle. UI is extremely minimal (avatar, name, one message, one reply), large type, generous whitespace, so it reads at a glance even at a slant.
- **Typography:** in-UI text is a clean grotesk, medium weight, large relative to the frame (bubble text ~1/25 frame height). Two-tone bubbles: neutral grey for agent, character-colour (yellow) for user — the agent's colour becomes the UI accent.
- **Color:** warm, desaturated environment (walnut wood, cream console, tungsten lamps) vs. saturated, glossy 3D mascots (cobalt blue, magenta, lime, mustard). Mascots pop as the only saturated elements.
- **Character design:** soft, inflated 3D blobs with two dot eyes and one accessory (beret, sunglasses, halo, bow tie). Personality comes from accessories and tiny idle motion (bob, blink, tilt), not from faces.
- **No captions or on-screen titles** in this range; narration/dialogue is implied (people speaking) but the recording is muted. Story is carried visually; the one piece of on-screen copy is the chat message, which does the "what it does" job.
- **Cursor:** the recorder's own macOS cursor sits over the player and the pause glyph is visible much of the time — an artifact of the screen recording, not a technique. Lesson for Jiro: if we record a page, hide cursor and player chrome.
- **Clarity of "what you're looking at":** name pill ("Alfred") appears before the chat UI, so when the header shows "Alfred" we already know who's talking. Establish identity, then show action.
- **Premium feel:** film-grade lighting and grading, real actors, practical set design, restraint (one message on screen, lots of negative space), and consistent mascot rendering quality.
