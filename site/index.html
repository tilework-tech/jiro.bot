Frequently asked questions

Who is Jiro?+

An AI software engineer for your team. Tag @jirobot in a conversation, and Jiro takes on the task, raises concerns early and hands back a pull request for review.

Which coding agents can I run?+

Claude Code, Codex, Gemini CLI, pi, Cursor Agent, OpenCode, or any agent that speaks the Agent Client Protocol. You can mix agents across tasks.

What can Jiro connect to?+

Any GitHub repository you can access, plus tools like Linear, Jira, Notion, Google Drive and Stripe. Each agent runs in its own single-tenant cloud environment with your repos and credentials in place.

How does billing work?+

Plans are sized by runtimes. Developer gives one user up to three, Team gives multiple users five shared ones, and Enterprise sets capacity to fit. Runtimes sleep when idle.

Who makes Jiro?+

Jiro is built by the Nori team.
