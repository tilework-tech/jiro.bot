>_ FAQ
Who is Jiro?+

An autonomous software engineer you call into a conversation. He takes on a task, raises concerns early, and hands back a pull request for review.

Which coding agents can I run?+

Claude Code, Codex, Cursor, DeepSeek, Pi, Gemini, and Goose. Any agent that speaks the Agent Client Protocol can be plugged into the Jiro ecosystem. Every agent runs on the same environment primitives, so you can mix agents across tasks or run several inside one workspace.

What repositories can I use?+

Any GitHub repository you have access to. Connect your GitHub account and select which repos to enable.

Can it work with our non-engineering tools?+

Jiro works with HubSpot, Google Sheets, Google Drive, Notion, Linear, Jira, Stripe, and Gmail, plus hundreds more. One agent across the stack, scoped per person, rather than a pile of logins. Ops, finance, and data teams describe the work in Slack or Teams the way they would ask a teammate. No CLI and no new dashboard.

What does an agent's environment look like?+

Each agent works in a single-tenant cloud environment with your repository, tools, dependencies, and access credentials layered in. No separate OAuth process for each tool or platform.

How does billing work?+

Plans are sized by runtimes. Developer gives one user up to three persistent runtimes, and Team gives multiple users five shared ones. Enterprise sets capacity to fit. Runtimes sleep when idle and wake on demand.

Is the output always a pull request?+

Agents can return a pull request, commit, comment, or completed task for you to review, merge, or send back. An output can also be a file when that is what the work produces: a document, a spreadsheet, a presentation, or another office artifact.

Why use cloud agents?+

Jiro is a cloud coding agent on a virtual machine that has your repos, credentials, and team context layered in. You hand off a task the way you would to a junior colleague, the agent works while you are on the road, and you can check in from your phone. Tasks can come from a Slack mention, a cron schedule, or a Linear ticket, so work starts without anyone at a keyboard.
