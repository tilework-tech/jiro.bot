## What this reference contributes to the final brief

1. Preserve the legible structural contrast: two aligned terminal windows inside a dark restaurant, labelled generic agent versus Jiro, with a single identical ticket above them. The meaningful demonstration is process quality: the generic agent introduces a broad special case and edits multiple files, while Jiro identifies adjustment ordering and writes a failing test. This is presented as a storyboard in the demo, not proof that any real code was executed.
2. Preserve the restaurant's copper, charcoal, cream, muted green, and warm-window-light hierarchy. The dark card interiors create readable room for code. Improve text contrast in the scene title and ticket line, which sit over a busy dim background.
3. Preserve a constant camera angle and smooth one-direction plate movement. In this excerpt, the code panes advance while the restaurant is still. Integrate the final continuous belt through adjacent scenes using a single physical route; this clip alone does not establish that route.
4. The reference is already dense: both panels fill most of the frame and nearly every belt position carries an object. For the requested calm final, trim on-screen motion outside the belt and code playback, reserve more breathing room, and follow the later white/faint-blue plate requirement.
5. The seal chef, onigiri face, fortune cookie, tea vessel, and left-entering covered item are useful starting points for gentle clickable surprises. No click behavior is demonstrated here, so any specific interaction assignment is a design proposal, not an observed feature.
