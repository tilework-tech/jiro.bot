# Asset manifest

Every shipped asset, generated by `pipeline/manifest.py`. The hash is the first 16 hex digits of its sha256. These files are the source of truth: a rebuild uses them as-is and only regenerates an asset if it is missing. Run `python pipeline/manifest.py && git diff docs/ASSETS.md` to prove nothing changed.
